# AiLab · постоянная страница подключения

В публичный репозиторий `Podgy89/ailab-miniapp` публикуются только `index.html`, `loader.css`, `loader.js`, `.nojekyll` и этот README. Это общий загрузчик, не исходники AiLab. Полный проект хранится отдельно в закрытом `Podgy89/AiLab`.

В ветке `runtime` хранится только `endpoint.json` с HTTPS-адресом туннеля и временем обновления. ПК обновляет его при смене адреса. Токен бота, GitHub-авторизация, модели, переписки и результаты не публикуются.

Загрузчик получает Telegram initData на своём постоянном origin, затем загружает интерфейс с ПК через защищённый `/api/ui`. CORS разрешает только origin настроенного GitHub Pages. При временной недоступности API загрузчик повторно узнаёт адрес и безопасно повторяет тот же запрос; идемпотентность заданий обеспечивает AiLab.

Статический GitHub Pages не выполняет модели и не хранит личные файлы. Компьютер и туннель должны работать. Скоростной лимит бесплатного туннеля сохраняется.
