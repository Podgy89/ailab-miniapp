# AiLab · постоянная страница подключения

Публичный репозиторий Podgy89/ailab-miniapp содержит общий загрузчик (index.html, loader.css, loader.js, .nojekyll, README) и зашифрованные ui-<sha256>.bin. Полный проект и открытые исходники интерфейса находятся только в приватном Podgy89/AiLab.

Пакет шифруется AES-256-GCM с новым случайным ключом и nonce. Ключ не публикуется: отдельное хранилище Windows DPAPI на ПК выдаёт его только через /api/ui/bootstrap после проверки подписи разрешённого владельца Telegram. Подпись и ключ никогда не отправляются GitHub. Браузер скачивает один шифротекст с Pages, проверяет SHA-256 и GCM, затем открывает интерфейс в памяти. Данные пользователя и модели в пакет не входят.

В ветке runtime хранится только endpoint.json с HTTPS-адресом туннеля и временем обновления. ПК обновляет его при смене адреса. CORS разрешает только origin настроенного GitHub Pages. API, модели, переписки и результаты остаются на ПК; Pages не выполняет вычисления.

Один короткий запрос на ПК заменяет сотни порционных запросов загрузки интерфейса. ПК и туннель всё равно должны работать; скорость передачи больших пользовательских медиа через туннель остаётся отдельным ограничением.
